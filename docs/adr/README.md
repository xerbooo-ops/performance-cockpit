# Architecture Decision Records

Architecture Decision Records (ADRs) dokumentieren verbindliche technische Entscheidungen einschließlich Kontext und Folgen.

Statuswerte:

- `Vorgeschlagen`
- `Angenommen`
- `Abgelöst`

Neue ADRs werden fortlaufend nummeriert und nach Annahme nicht überschrieben. Änderungen erfolgen durch eine neue ADR, die auf die abgelöste Entscheidung verweist.
